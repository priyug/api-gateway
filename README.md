This project is a Spring Boot Microservices-based application consisting of User Service, Post Service, and Notification Service.
The application uses Spring Cloud Gateway as a centralized entry point for routing client requests to individual microservices and Netflix Eureka Server for service registration and discovery.
The microservices communicate with each other using RestTemplate for synchronous REST-based communication.

API Gateway – Central entry point for all client requests.
Eureka Server – Service registry that maintains information about registered microservices.
